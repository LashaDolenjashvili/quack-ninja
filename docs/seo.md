# SEO Maintenance Guide

This document describes the current technical SEO setup for QuackNinja and how to maintain it safely.

## Indexing scope

### Intended indexable routes

- `/` (homepage in `app/(marketing)/page.tsx`)
- `/pricing`
- `/docs`
- `/docs/quickstart`
- `/docs/import/csv`
- `/docs/import/excel`
- `/docs/import/parquet`
- `/docs/export`
- `/docs/session`
- `/docs/troubleshooting`
- `/terms-and-conditions`
- `/privacy-policy`
- `/refund-policy`

### Intended non-indexable routes

- `/app/*` (editor/workspace area)
- `/auth/*` (auth flows)
- `/api/*` (API endpoints)

Noindex is currently applied at:

- `app/app/layout.tsx`
- `app/auth/layout.tsx`

## robots.txt

Generated by `app/robots.ts`.

Current behavior:

- Allows crawl by default
- Disallows `/api`, `/auth`, `/app`, and `/_next`
- Adds sitemap directive pointing to `${SITE_URL}/sitemap.xml`

`SITE_URL` is resolved from:

1. `NEXT_PUBLIC_SITE_URL`
2. `NEXT_PUBLIC_APP_URL`
3. fallback: `https://www.quackninja.com`

Additional SEO env vars:

- `NEXT_PUBLIC_GOOGLE_SITE_VERIFICATION`: optional Google Search Console verification token
- `NEXT_PUBLIC_BRAND_PROFILE_URLS`: optional comma-separated list of official public brand profile URLs used for `sameAs`

## sitemap.xml

Generated by `app/sitemap.ts`.

- Includes static indexable routes only
- Excludes internal routes (`/app`, `/auth`, `/api`)
- Uses build-time `lastModified` fallback (`new Date()`)

To add a newly indexable page:

1. Add metadata to that page with `buildMetadata(...)` from `lib/seo.ts`
2. Add the route path to `indexableRoutes` in `app/sitemap.ts`
3. Ensure route is not inside noindex-only areas

## Metadata helpers

SEO helper module: `lib/seo.ts`

Use:

```ts
import type { Metadata } from "next";
import { buildMetadata } from "@/lib/seo";

export const metadata: Metadata = buildMetadata({
  title: "Page title",
  description: "Page description",
  path: "/path",
  keywords: ["brand term", "topic term"],
});
```

Global defaults are set in `app/layout.tsx`:

- `metadataBase`
- title template
- default description
- OpenGraph defaults
- Twitter card defaults

## Structured data

JSON-LD component: `components/JsonLd.tsx`

Helpers:

- `buildOrganizationJsonLd()`
- `buildWebsiteJsonLd()`
- `buildSoftwareApplicationJsonLd(...)`
- `buildFaqJsonLd(...)`

`buildOrganizationJsonLd()` now adds:

- organization description
- `alternateName` for spacing variants such as `Quack Ninja`
- `sameAs` only when official profile URLs are provided via env

Current usage:

- Homepage: Organization + WebSite + SoftwareApplication + FAQPage

Important:

- Only add FAQ schema for content that is visibly rendered on the page.

## Validation checklist

1. `GET /robots.txt` returns `200` and includes `Sitemap`.
2. `GET /sitemap.xml` returns `200` and includes only intended indexable routes.
3. View page source for key pages (`/`, `/pricing`, `/docs`) and confirm:
   - title
   - meta description
   - canonical
   - OG/Twitter tags
4. Confirm `/app/*` and `/auth/*` include noindex metadata.
5. Validate schema in:
   - Google Rich Results Test
6. Validate crawl/index behavior in:
   - Google Search Console URL Inspection
